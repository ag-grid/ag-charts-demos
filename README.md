# AG Charts Demos

Demo apps for the AG Charts examples showcased on https://www.ag-grid.com/charts/examples/.

This repository is generated from
[`packages/ag-charts-demos/seeds`](https://github.com/ag-grid/ag-charts/tree/latest/packages/ag-charts-demos/seeds) in
[ag-grid/ag-charts](https://github.com/ag-grid/ag-charts), and each sync replaces its content:
raise changes there rather than here.

## Running a demo

Each demo is a standalone project. From its folder:

```bash
npm install
npm run dev
```
